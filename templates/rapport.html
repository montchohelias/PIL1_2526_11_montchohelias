Architecture

L'application suit une architecture client-serveur avec :

  • Frontend : HTML5, CSS3, JavaScript, Bootstrap 5
  • Backend : Python 3.x avec Flask
  • Base de donnees : PostgreSQL

Modele de donnees

La base de donnees relationnelle comprend les entites principales :

  • User : Gestion des comptes utilisateurs
  • Competence : Referentiel des competences
  • Offre : Offres et demandes de mentorat
  • Matching : Correspondances mentor-mentore
  • Conversation & Message : Systeme de messagerie

Algorithme de Matching

L'algorithme calcule un score composite base sur trois criteres ponderes :

Critere Poids Description
Compatibilite des competences 40% Intersection entre competences du mentor et lacunes du mentore
Compatibilite des horaires 35% Recouvrement des creneaux disponibles
Proximite des filieres 25% Correspondance filiere/niveau avec bonus si mentor plus avance

Instructions de deploiement

  1. Installer Python 3.9+ et PostgreSQL
  2. Configurer PostgreSQL avec un utilisateur et une base de donnees
  3. Installer les dependances : pip install -r requirements.txt
  4. Configurer config.py avec les identifiants PostgreSQL
  5. Initialiser la BDD : flask init-db
  6. Lancer l'application : python app.py
